# Supporting Information

The following files are submitted as editable, machine-readable Supporting
Information Tables. They preserve the source snapshot, identity decisions,
evidence tiers, and unresolved status used in the manuscript.

## Table S1. Claims–terpene evidence matrix

[`../../data/claims-terpene-matrix.csv`](../../data/claims-terpene-matrix.csv)
contains the 109 marked compound–effect rows derived from the Terpedia source
matrix, with source counts, evidence fields, and effect-support status.

## Table S2. Receptor hypothesis map

[`../../data/receptor-hypothesis-map.csv`](../../data/receptor-hypothesis-map.csv)
maps named compounds to candidate receptor or protein targets, evidence tiers,
interpretation boundaries, and literature identifiers.

## Table S3. Prioritized hypotheses-to-test table

[`../../data/hypotheses-to-test.csv`](../../data/hypotheses-to-test.csv)
specifies 14 falsifiable experiments, including controls, primary endpoints,
and rules for interpreting positive or null findings.

## Table S4. Derived hypothesis register

[`../../data/hypothesis-register.csv`](../../data/hypothesis-register.csv)
provides the derived row-level hypothesis register used to audit the mapping
from promotional claims to testable propositions.

All four tables are supporting evidence infrastructure, not claims that any
compound produces a therapeutic effect.
